# Facebook-inlägg för Hundkrets

Här finns olika versioner av Facebook-inlägg anpassade för olika typer av grupper.

## Filstruktur

| Fil | Målgrupp |
|-----|----------|
| `01_allmanna_hundgrupper.md` | Allmänna hundgrupper och hundforum |
| `02_lokala_grupper.md` | Lokala Facebook-grupper (byt ut [ORTSNAMN]) |
| `03_entrepenor_grupper.md` | Entreprenör- och startup-grupper |
| `04_foralder_grupper.md` | Förälder- och familjegrupper |
| `05_hundforum_detaljerade.md` | Hundforum (mer detaljerade förklaringar) |

## Tips för användning

1. **Anpassa [ORTSNAMN]** - I fil `02_lokala_grupper.md`, byt ut `[ORTSNAMN]` mot namnet på orten/gruppen

2. **Välj rätt version** - Varje fil har 3 versioner med olika längd och ton:
   - Version 1: Balanserad
   - Version 2: Story-fokus
   - Version 3: Kort och direkt

3. **Blanda och matcha** - Du kan kombinera delar från olika versioner

4. **Lägg till bilder** - Inlägg med bilder får oftast mer uppmärksamhet

## Viktiga punkter att behålla

- Personlig ton
- Äkthet (83 medlemmar, en månad gammal)
- Gratis och enkel förklaring
- Call-to-action (dela gärna)
- Länken https://hundkrets.se
